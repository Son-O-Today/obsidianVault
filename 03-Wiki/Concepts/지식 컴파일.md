# 지식 컴파일

## 정의

지식 컴파일은 여러 원천 자료에서 사실과 관계를 추출해, 반복 탐색하기 쉬운
개념·엔티티·비교·목차 페이지로 변환하는 과정이다.

## 입력과 출력

```text
00-Inbox의 미처리 입력
-> 01-Raw의 검토된 원본
-> 03-Wiki의 원자적 지식
-> 04-MOCs의 탐색 지도
-> 05-Graphs의 관계 분석
```

## 컴파일 원칙

- 원본은 수정하지 않고 출처로 보존한다.
- 같은 주제의 기존 Wiki가 있으면 새 파일보다 병합을 우선한다.
- 하나의 페이지는 하나의 명확한 개념이나 운영 문제를 다룬다.
- 사실, 해석, 추론을 구분한다.
- 모순은 삭제하지 않고 `contradicted` 또는 명시적 쟁점으로 남긴다.
- 중요한 새 페이지는 관련 MOC에 연결한다.

## 품질 기준

- 주요 주장에 원본 링크가 있다.
- 제목과 소제목만 읽어도 페이지의 범위를 알 수 있다.
- 관련 페이지로 나가는 wikilink가 있다.
- 독립적으로 읽을 수 있으면서 다른 페이지와 연결된다.
