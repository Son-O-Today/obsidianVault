# AI 에이전트 지식 운영

## 목표

에이전트가 매 세션마다 같은 시스템과 실패 사례를 처음부터 다시 발견하지 않도록
운영 지식을 지속 가능한 기억으로 관리한다.

## 저장할 지식

- 작업 중 발생한 실패와 해결책
- 저장소별 실행·배포·복구 절차
- 중요한 설계 결정과 그 이유
- 반복 질문과 검증된 답변
- 에이전트가 자주 하는 실수와 금지 사항

## 처리 흐름

1. 대화와 실행 로그를 `00-Inbox` 또는 `01-Raw`에 보존한다.
2. 반복 가치가 있는 내용을 [[지식 컴파일]]한다.
3. 결과를 `03-Wiki`의 문제·해결·시스템 페이지에 병합한다.
4. [[Graphify]]로 관련 시스템과 운영 절차의 연결을 탐색한다.
5. 에이전트는 새 작업 전에 MOC와 그래프 질의를 우선 사용한다.

## 운영 통제

- 원본과 컴파일 결과의 소유 영역을 분리한다.
- 동시 편집 전 Git 최신 상태를 확인한다.
- 불확실한 추론은 사실처럼 저장하지 않는다.
- 중요한 자동 변경은 사람이 검토할 수 있는 commit으로 남긴다.
